Set up Wi-Fi

Sync your phone and alarm clock over the same local network.

  1. Connect your phone to the clock over Bluetooth.
  2. Open Clock → Local Wi-Fi and enable Wi-Fi connection and sync.
  3. Enter the 2.4 GHz network name and password. The phone must be able to reach the clock on the same local network.
  4. Tap Send Wi-Fi settings to clock and wait for ESP32 reachable over Wi-Fi.
  5. If the clock fails to reconnect after a network change, tap Retry Wi-Fi connection or resend the settings over Bluetooth. Check whether the guest network isolates devices.

Bluetooth remains available if Wi-Fi is down. Return to the initial setup.
