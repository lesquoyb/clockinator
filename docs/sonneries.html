Change the ringtone

Prepare a WAV file, upload it to the clock and assign it to a routine.

Prepare the file

The firmware plays 8-bit or 16-bit PCM WAV files in mono or stereo. A 16-bit mono WAV is a good starting point. Trim the audio in an editor and export it as signed 16-bit PCM WAV. To convert it with FFmpeg, run the following command.

ffmpeg -i source.mp3 -ac 1 -ar 22050 -c:a pcm_s16le alarm.wav

Upload and select the ringtone

  1. Connect to the clock in the app, open Clock → Device ringtones and tap Upload WAV to device.
  2. Choose the WAV and wait for it to appear under Files on device.
  3. Under Routines, edit the routine and select the file in Sound & snooze. Save and sync.
  4. Set an alarm a few minutes ahead to test it. Adjust the volume under Clock → Clock ringtone volume.
